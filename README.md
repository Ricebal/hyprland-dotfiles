# Rice's Hyprland Dotfiles
My dotfiles for wayland compositor hyprland. Tested on Fedora and Arch linux.

## Dependencies
This config requires some packages to be installed.

### Required
```
Hyprland 0.56+ hyprlock hyprpaper wlogout kitty waybar wofi python-pywal
```

### Optional
```
visual-studio-code neovim imv dolphin zen-browser
```

#### Yazi
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup update
```
```bash
cargo install --locked yazi-fm yazi-cli
```

## Extra information
Uses Hyprland's Lua config system, with per-host modules selected from the
hostname cache generated by `~/.local/scripts/sethostname`. Pywal supplies the
window border colors; built-in fallback colors are used until Pywal has run.
